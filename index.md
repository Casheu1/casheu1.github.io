# 🦖 perplexity-2api-python - Easy Automation for Everyone

## 🚀 Overview
perplexity-2api-python offers a simple way to automate your tasks online. This application uses advanced features such as Cloudflare Turnstile for bypassing challenges, mouse trajectory simulation, and cookie management, making it perfect for users who want an efficient browsing experience.

## 🐾 Features
- **Dual Engine Support:** Utilizes Botasaurus and Playwright for robust automation.
- **Smart Bypass:** Cloudflare Turnstile handling for seamless online access.
- **Mouse Simulation:** Realistic mouse movement using Bezier curves.
- **Cookie Management:** Automatically maintains and saves cookies for you.
- **Anonymous Browsing:** Keep your identity safe with advanced stealth modes.
- **OpenAI Compatibility:** Fully integrates with OpenAI’s API for streaming tasks.
- **Multi-Account Support:** Manage several accounts smoothly.
- **User-Friendly Setup:** Visual configuration tool supports HAR and cURL file parsing.

## 🔍 System Requirements
- **Operating System:** Windows 10 or later, MacOS, or Linux
- **Memory:** At least 4GB of RAM
- **Storage:** 200MB of free disk space
- **Network:** Stable internet connection
